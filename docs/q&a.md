# Вопросы и ответы

## Через какого поставщика вызываются языковые модели?

Все вызовы идут через OpenRouter по совместимому с OpenAI адресу `https://openrouter.ai/api/v1`.

## Какие модели выбраны?

- Основная модель: `google/gemini-3.7-flash`.
- Резервная модель: `openai/gpt-5.6-luna`.
- Уровень рассуждения: `low`.

Основная модель рассчитана на частые запросы планировщика и формирование отчётов с умеренной стоимостью. Резервная используется только после повторов временно неуспешного запроса.

## Какие переменные нужны для запуска?

Обязательны `AGENT_API_KEY` и, для настоящих ответов модели, `OPENROUTER_API_KEY`. Остальные настройки OpenRouter уже имеют значения по умолчанию в `env.example`.

## Что произойдёт без ключа OpenRouter?

Служба агента запустится, но планировщик и формирование отчёта будут использовать детерминированные локальные имитационные ответы. Это позволяет проверять контейнеры, протоколы и пользовательский интерфейс без расходов на модель.

## Как устроено переключение моделей?

Клиент повторяет запрос при ограничении частоты, сетевой ошибке, превышении времени ожидания и серверных ошибках. После исчерпания повторов он обращается к `OPENROUTER_FALLBACK_MODEL`.

## Поддерживается ли структурированный вывод?

Да. Сначала клиент запрашивает ответ по схеме JSON. Если модель или маршрут не принимает этот формат, выполняется попытка с обычным объектом JSON, затем с вызовом инструмента.

## Как контролировать стоимость?

В журналах сохраняются фактическая модель, число входных, кэшированных и выходных токенов, а также стоимость, если OpenRouter вернул её. Текст запроса, ответа и ключ доступа не записываются.

## Откуда берутся рыночные данные?

Из официального программного интерфейса MOEX ISS через отдельный MCP-сервер `moex-iss-mcp`. Расчёты риска выполняются в `risk-analytics-mcp`.

## Как запустить весь проект локально?

```bash
cp env.example .env
# заполните AGENT_API_KEY и OPENROUTER_API_KEY
make local-up
```

После запуска веб-приложение доступно по адресу `http://localhost:3000`, агент — по `http://localhost:8100`, MCP-серверы — на портах `8000` и `8010`.
